## 0. 必须先报告的一件事：V2.5 论文结论三所依据的数据是坏的

V2.5 论文的**结论三**（也是自适应步长这个课题的立项理由）写着：

> 在权威 Type III 问题 dMOP1A（解集静止、仅前沿旋转）上，$\alpha=0.5$ 以
> **0.0251 对 0.0570** 大幅领先 $\alpha=1.0$（$p=1.86\times10^{-9}$，相对改进 **127%**），
> 因此"解集静止时全步外推有害"，需要自适应步长。

本轮复核发现：**其中的 $\alpha=1.0$ 数值来自一个坏数据文件，无法复现。**

### 证据链

1. **A/B 对照**：把代码切到生成该数据的版本（commit `3c83f2c`）与当前工作树，
   用**完全相同的 8 个种子**重跑 dMOP1A/τ=25/`ldt_alpha1`：
   ```
   FROZEN 3c83f2c : ldt_alpha1 mean=0.02563  sd=0.01657  per-seed=[0.02744, 0.06812, 0.02123, 0.02090]
   CURRENT tree   : ldt_alpha1 mean=0.02563  sd=0.01657  per-seed=[0.02744, 0.06812, 0.02123, 0.02090]
   ```
   两者逐位相同 → **v3.0/v3.1 的改动没有造成这个差异。**

2. **同一驱动脚本复现**：用生成该数据的驱动 `experiments/run_v25_alpha.py`
   重跑同一配置、同一 30 个种子，得到 **0.02563**（8 种子）／**0.02507**（30 种子），
   而磁盘上冻结的文件是 **0.05697**。

3. **全量陈旧性审计**（`scripts/staleness_audit.py`，13 个"问题 × 算法"组合逐一对拍）：

   | 检查项 | 结果 |
   |---|---|
   | 逐位完全一致 | **12 / 13** |
   | 不一致 | **1 / 13 → DMOP1A τ=25 `ldt_alpha1`：冻结 0.05697 vs 重算 0.02507（+127.2%）** |

   即：**v2.5 数据集里只有这一个格子是坏的**，恰好就是结论三所引用的那一格。
   其余 12 格（含 $\alpha=0.5$ 在 dMOP1A 上的 0.02510）全部逐位复现。

### 更正后的结论

在 dMOP1A 上，用正确的数据：

| 变体 | 稳态 MIGD（30 种子） |
|---|---|
| $\alpha=0.5$（半步） | 0.02510 |
| $\alpha=1.0$（全步） | 0.02507 |
| 自适应 | 0.02509 |

配对 Wilcoxon（自适应 vs 全步）：**15 个配置中 0 个显著**，dMOP1A 上两者差 **0.1%**。

> **所以：dMOP1A 上并不存在"解集静止时全步外推有害"的现象。**
> 原来的 127% 是坏数据造成的假象。

**这直接推翻了两件事**：(a) V2.5 论文结论三；(b) 自适应步长课题的立项理由——
既然固定全步在 dMOP1A 上并没有变差，就没有"必须把步长调小"的场景。

## 1. 自适应规则的设计与实现

按方案 3.1 实现，`algorithms/ldmt_nsga2.py` 的 `LDTNSGA2Adaptive`（id `ldt_adaptive`）：

```
movement = ||mu_e - mu_{e-1}||_2 / sqrt(D)          # 决策空间中心位移（逐维归一）
noise    = mean_j  bootstrap-SD(中心第 j 维)         # 中心估计不确定性
ratio    = movement / noise
s_k      = clip((ratio - gamma) / (2*gamma), 0, 1)
alpha_k  = alpha_min + (alpha_max - alpha_min) * s_k
```

方案 3.1 明确要求"区分决策空间中心的移动证据与目标空间变化量"，
因此步长**只由决策空间位移决定**，不使用 $D_k$（$D_k$ 仍供可选的 $\sigma$ 缩放使用）。
默认 `alpha_min=0.5, alpha_max=1.0, gamma=1.0`，首次变化取保守端（无预测残差可依）。

**校准结果**（`scripts/calibrate_adaptive_alpha.py`，真实环境上实测）：

| 问题 | 类型 | mean(ratio) | mean(alpha_k) |
|---|---|---|---|
| FDA1 | I | 9.75 | 1.000 |
| FDA4 | I | 7.08 | 1.000 |
| DMOP2A | II | 15.57 | 1.000 |
| DMOP3A | I | 30.37 | 1.000 |
| **DMOP1A** | **III** | 8.27 | **0.686** |

机制方向是对的：真正平移的解集 ratio 在 4–38，α_k 顶到 1.0；
而 dMOP1A 在种群收敛后（第 2 次变化起）ratio 降到 **0.56–0.58**，α_k 落到 **0.5** 下限。

## 3. 结论（如实）

1. **自适应步长没有带来可检测的收益。** 自适应与固定 $\alpha=1.0$ 在**全部 15 个配置**上
   统计不可区分（改进幅度 −0.8% ~ +0.2%）。在本文的基准上，
   **固定全步是更简单且同样好的选择**。

2. **自适应也没有解决任何固定步长解决不了的问题。** 因为那个"问题"本身不存在——
   见第 0 节：dMOP1A 上固定全步并不变差（0.02507 对 0.02510）。

3. **机制本身确实按设计工作。** α_k 在平移问题上顶到 1.0、在 dMOP1A 收敛后落到 0.5 下限，
   与设计意图一致；它只是**没有转化为性能收益**。此外 dMOP1A 的前两次变化会误判为
   "在移动"（种群仍在向静止解集收敛，中心位移大），说明该判据对"尚未收敛的静止解集"
   会给出假阳性。

4. **代价是真实的**：自适应臂的迁移耗时 0.0672 s，比固定 α=1.0 的 0.0439 s **高 53%**
   （每次变化要做 bootstrap 估计）。收益为零、开销 +53%，**不推荐作为默认机制**。

5. **比"自适应"更硬的结论**（本轮可证）：在这个基准族上，
   **步长取全步（α=1.0）显著优于半步（11/15 配置）与零步（14/15 配置）**，
   且与 PPS 互有胜负（5 胜 2 负 8 平）。
